## 📋 Quick Deployment Overview

### Step 1: Deploy Backend (5 min)
1. Go to [vercel.com/new](https://vercel.com/new)
2. Import your GitHub repository
3. Configure:
   - Root Directory: `.` (root)
   - Framework: Other
4. Add environment variables (7 variables)
5. Deploy!

### Step 2: Deploy Frontend (5 min)
1. Go to [vercel.com/new](https://vercel.com/new) again
2. Import SAME repository
3. Configure:
   - Root Directory: `client` ⚠️ Important!
   - Framework: Next.js
4. Add environment variable (1 variable)
5. Deploy!

### Step 3: Connect Them (2 min)
1. Update `CLIENT_URL` in backend with frontend URL
2. Redeploy backend
3. Done! 🎉

## 🔑 Environment Variables You'll Need

### Backend (7 variables)
```env
NODE_ENV=production
PORT=5000
MONGO_URI=<check your .env file>
JWT_SECRET=<check your .env file>
CLOUDINARY_CLOUD_NAME=<check your .env file>
CLOUDINARY_API_KEY=<check your .env file>
CLOUDINARY_API_SECRET=<check your .env file>
CLIENT_URL=<your-frontend-url-after-deployment>
```

### Frontend (1 variable)
```env
NEXT_PUBLIC_API_URL=<your-backend-url>/api
```

**Where to find these?** Check your `.env` and `client/.env.local` files!
